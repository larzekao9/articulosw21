# 🎬 LUMEN CINEMA - Artículo Interactivo

Versión web futurista del artículo académico sobre el desarrollo e integración de un sistema de gestión cinematográfica con Inteligencia Artificial de voz local.

## 📖 Descripción

Este proyecto presenta una versión HTML interactiva y visualmente atractiva del artículo **"Desarrollo e Integración de un Sistema de Gestión Cinematográfica con Inteligencia Artificial de Voz Local"** por **Arze Kao Luis Angel** de la Universidad Autónoma Gabriel René Moreno (UAGRM).

## ✨ Características

### Diseño Futurista
- **Tema Cyberpunk/Neón** con colores vibrantes (verde, azul, rosa)
- **Glassmorphism** con efectos de vidrio translúcido
- **Sombras neon** resplandecientes
- **Grid animado** en el fondo

### Interactividad
- ✅ **Tabla de contenidos interactiva** en el sidebar
- ✅ **Navegación sticky** con efectos hover
- ✅ **Highlighting automático** de sección actual
- ✅ **Botón flotante** para volver arriba
- ✅ **Parallax 3D** en elementos al mover el mouse
- ✅ **Scroll suave** entre secciones

### Responsivo
- 📱 Funciona perfectamente en móviles
- 💻 Optimizado para desktop
- 🎨 Tema oscuro automático

## 🚀 Desplegar en Vercel

### Opción 1: Desde la web
1. Ve a [vercel.com](https://vercel.com)
2. Conecta tu cuenta de GitHub
3. Selecciona el repositorio `articulosw21`
4. Vercel desplegará automáticamente

### Opción 2: Desde la CLI
```bash
npm i -g vercel
cd /ruta/al/proyecto
vercel
```
