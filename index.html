◆ Resumen Ejecutivo y Planteamiento del Problema

La interacción tradicional con sistemas de gestión cinematográfica requiere que los usuarios recorran diferentes interfaces para consultar películas, seleccionar funciones, elegir butacas y completar una compra.

El proyecto LUMEN CINEMA – AI PRECISION KIOSK plantea una alternativa revolucionaria basada en un agente de voz con Inteligencia Artificial local, capaz de interpretar instrucciones expresadas mediante lenguaje natural y conectarlas con las operaciones del sistema cinematográfico.

La propuesta integra tecnologías de reconocimiento de voz, procesamiento de lenguaje natural, modelos de lenguaje y síntesis de voz, manteniendo la ejecución de las operaciones bajo el control de una arquitectura backend determinista.

🔧 Mi Participación

Dentro del proyecto, mi participación se concentra principalmente en el desarrollo backend relacionado con el catálogo y la configuración del sistema cinematográfico, trabajando sobre las entidades y operaciones necesarias para administrar películas, salas, precios, cartelera y promociones.

◆ 2.1 Detección de Actividad de Voz

Tecnología: Silero VAD

Su función es determinar cuándo existe actividad de voz y delimitar las intervenciones del usuario, proporcionando un mecanismo eficiente para capturar el audio relevante sin captar ruido de fondo.

◆ 2.2 Reconocimiento Automático del Habla

Tecnología: Whisper mediante faster-whisper

Convierte la señal de audio en texto para posteriormente permitir su interpretación. El proyecto utiliza vocabulario contextual relacionado con el dominio cinematográfico, como películas, entradas, butacas y productos de dulcería.

◆ 2.3 Comprensión y Decisión

Tecnología: Llama 3.2

El modelo interpreta la intención del usuario y determina las herramientas que deben ser utilizadas mediante el patrón ReAct y mecanismos de Tool Calling.

◆ 2.4 Síntesis de Voz

Tecnología: Piper

Genera la respuesta de audio que será presentada al usuario, manteniendo la comunicación fluida y natural.

◆ Arquitectura Local / Edge

Una característica central del proyecto es el procesamiento local de los componentes de Inteligencia Artificial. Esta decisión de diseño ofrece múltiples ventajas competitivas:

◆ Criterio ⚡ Procesamiento Local
🔐 Privacidad Los datos pueden mantenerse dentro de la infraestructura local
🔗 Dependencia Reduce la dependencia de APIs externas
⚡ Latencia Evita depender completamente de la comunicación con servidores externos
🏗️ Infraestructura Requiere capacidad de procesamiento local

El procesamiento Edge constituye una decisión de diseño orientada a reducir la dependencia de servicios externos y mantener el procesamiento de IA dentro de la infraestructura disponible.

◆ Análisis Comparativo de Aplicaciones Existentes

El proyecto considera diferentes soluciones relacionadas con agentes de voz y procesamiento de audio:

◈ Buzz / Buzz Captions

Herramienta enfocada principalmente en el reconocimiento de voz mediante Whisper ejecutado localmente.

◈ ElevenLabs Conversational AI

Solución que integra reconocimiento de voz, modelos de lenguaje y síntesis de voz mediante infraestructura en la nube.

◈ Hume AI

Solución orientada a interfaces conversacionales que incorpora capacidades relacionadas con el análisis emocional.

En LUMEN CINEMA se priorizan las capacidades necesarias para resolver el flujo transaccional cinematográfico, haciendo énfasis en el procesamiento local y el control determinista de operaciones.

◆ Caso de Estudio Principal: LUMEN CINEMA

◆ 6.1 Arquitectura de Comunicación

El sistema contempla comunicación bidireccional mediante WebSocket, utilizada para transmitir audio y sincronizar la interacción entre el agente y la interfaz en tiempo real.

◆ 6.2 Arquitectura de Agente Supervisado

El sistema sigue un principio fundamental:

« El modelo propone, el código decide. »

Las operaciones críticas permanecen bajo el control de reglas deterministas. Esto incluye:

  • 💰 Precios
  • 🪑 Disponibilidad de asientos
  • 🧮 Cálculo de totales
  • 📊 Operaciones transaccionales
  • ✔️ Confirmaciones

Antes de ejecutar operaciones que persistan información o generen cobros, se solicita confirmación explícita del usuario.

◆ 6.3 Separación de Roles

Las herramientas se encuentran segmentadas según el rol del usuario:

  • 👥 CLIENTE: Acceso a consultas, compras y operaciones transaccionales
  • ⚙️ ADMINISTRADOR: Acceso a configuración, gestión de catálogo y reportes

◆ Lecciones Aprendidas y Filosofía de Diseño

◈ 9.1 El modelo propone, el código decide

La IA interpreta el lenguaje natural, pero la ejecución de las operaciones permanece bajo el control del backend. Esta filosofía garantiza que las operaciones críticas se ejecuten de manera segura y predecible.

◈ 9.2 La voz debe ser concisa

Las respuestas habladas deben evitar ser excesivamente extensas y utilizar la interfaz visual cuando sea necesario mostrar información detallada. Esto mejora la experiencia del usuario y reduce la carga cognitiva.

◈ 9.3 La IA como interfaz

El agente de voz funciona como una nueva interfaz de interacción con el sistema, mientras que las reglas de negocio continúan siendo controladas por el software. Es un complemento, no un reemplazo de las interfaces existentes.

◆ Conclusiones

El desarrollo de LUMEN CINEMA demuestra la integración de Inteligencia Artificial de voz local con un sistema de gestión cinematográfica de nueva generación.

Desde mi participación en el backend, el desarrollo del catálogo y la configuración proporciona la estructura necesaria para que las operaciones del sistema trabajen con información organizada y controlada.

La integración entre Inteligencia Artificial, backend y base de datos permite construir una arquitectura en la que el modelo de lenguaje interpreta las solicitudes del usuario, mientras que el sistema de negocio mantiene el control sobre las operaciones reales.

Este enfoque demuestra que la IA no reemplaza el control determinista del software, sino que lo complementa, creando una experiencia de usuario superior sin sacrificar la seguridad y la integridad de los datos.
